# João Gabriel — Portfólio

Portfólio pessoal desenvolvido com **React + Vite** para apresentar meus projetos, estudos e evolução na área de tecnologia, transformando ideias em experiências digitais.

## Sobre

Sou estudante do último período do curso técnico em Informática para Internet e estou construindo minha experiência por meio de projetos próprios.

Atualmente, meu foco está em:

- Desenvolvimento Web
- React e JavaScript
- Cibersegurança
- Inteligência Artificial

## Tecnologias

- React
- Vite
- JavaScript
- HTML5
- CSS3

## Insights

A antiga seção "Projetos" virou **Insights**: cada projeto é apresentado pela ideia que o originou (observação, ideia e o que foi construído).

- Conecta Cuidado
- Biblioteca Livre
- Destrava Dívidas

Para adicionar um novo insight, inclua um objeto no array `insights` em `src/App.jsx`.

## Como executar

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

## Configuração dos links

Antes de publicar, preencha no topo de `src/App.jsx`:

- `GITHUB_URL`
- `EMAIL`

Links vazios ficam ocultos automaticamente. O `LINKEDIN_URL` já está configurado.

A foto de perfil está em `public/foto-perfil.jpg`.

## Desenvolvimento contínuo

Este portfólio não é um projeto final: ele acompanha minha evolução como desenvolvedor. Novos projetos, estudos e melhorias serão adicionados ao longo do tempo.
